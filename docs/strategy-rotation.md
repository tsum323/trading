# Спецификация: rotation 0.1.0 — недельная ротация по силе

Статус: **гипотеза, зафиксирована до первого прогона.** Документ написан и
закоммичен до того, как ротация запускалась на данных исследовательской
части. Ничего в нём не утверждает, что стратегия прибыльна.

## 0. Контекст

Восемь конфигураций на сигналах отвергнуты (`research/journal.jsonl`).
Общая причина — частые сделки: издержки (≈ 0,24% цены за круг) съедают
небольшое преимущество, если оно есть. Ротация торгует раз в неделю и
сравнивает монеты **между собой** (cross-sectional momentum), а не каждую с её
прошлым. Эффект «сильные монеты остаются сильными на горизонте недель»
описан в исследованиях крипторынка; правила ниже — круглые стандартные
значения, а не подобранные.

## 1. Гипотеза

**H1.** Если раз в неделю держать две монеты корзины с наибольшим ростом за
28 дней (и не держать монеты с отрицательным ростом), средняя недельная
доходность после издержек положительна и выше, чем у случайного выбора того
же числа монет.

**H0.** Средняя недельная доходность не отличается от случайного выбора
монет с той же долей вложенного капитала.

## 2. Правила (идентификатор `rotation`, версия `0.1.0`)

| Параметр | Значение |
|---|---|
| Корзина | BTC, ETH, SOL, BNB, XRP, ADA, DOGE, TRX к USDT (та же 8, что в прежних проверках на корзине) |
| Данные | дневные свечи Binance Spot (публичные, UTC) |
| Решение | каждый понедельник 00:00 UTC, по дневным свечам, закрытым к этому моменту |
| Сила монеты | close последней закрытой свечи / close 28 дней назад − 1; нужна полная история за 28 дней |
| Портфель | две монеты с наибольшей силой, по 50%; монета с силой ≤ 0 не берётся, её доля — в USDT (доход 0) |
| Исполнение | по open дневной свечи понедельника; издержки — комиссия 0,1% и проскальзывание 0,02% с переставленного объёма |
| Доходность недели | open понедельника → open следующего понедельника, после издержек перестановки |

Учитываются недели, которые целиком лежат внутри части разбиения. Первая
неделя покупает портфель с нуля (издержки на весь вложенный объём).

## 3. Контроль и сравнения

- **Случайная ротация** (критерий): каждую неделю — столько же монет, сколько
  держит стратегия (0, 1 или 2), выбранных случайно из корзины, с теми же
  долями и издержками; 1000 прогонов, сравнение средней недельной доходности
  с 95-м перцентилем.
- Для справки, не критерий: корзина поровну с еженедельной перестановкой и
  удержание BTC.

## 4. Критерии отказа

1. Меньше 52 недель — «не определено».
2. Отказ, если нижняя граница 95% интервала (бутстреп по неделям) средней
   недельной доходности после издержек ≤ 0.
3. Отказ, если средняя недельная доходность не выше p95 случайной ротации.
4. Отказ, если больше 50% суммарного логарифмического прироста дал один месяц.
5. Отказ, если больше 50% суммы положительных вкладов дала одна монета.

Порядок: research → validation (только при прохождении всех критериев) →
holdout один раз для версии.

ETH, SOL, BNB, XRP), потому что с ней запущены остальные персонажи; его
правила не меняются, чтобы не смешивать журнал. Эта проверка — про 8 монет.
